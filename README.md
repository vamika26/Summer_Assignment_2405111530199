## Assignment Guidelines

### Daily LeetCode Solutions
- Upload your daily LeetCode solutions in the corresponding `Day_X` folder within each week
- Use meaningful file names that describe the problem
- Include comments explaining your approach
- Commit and push your code **on the same day** after completing the assigned work

### Weekly OOPS Assignment
- Upload your weekly OOPS (Object-Oriented Programming System) solutions in the `OOPS` folder of the respective week
- Use meaningful file names that describe the assignment
- Include proper documentation and comments
- Commit and push your code on the same day after completing the assignment

## File Naming Convention

Use clear, descriptive names for your files:
- **LeetCode solutions**: `problem_name.py`, `problem_name.java`, `problem_name.cpp`, etc.
- **OOPS assignments**: `assignment_name.java`, `assignment_name.cpp`, etc.
